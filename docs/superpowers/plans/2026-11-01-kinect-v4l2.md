# Kinect v2 V4L2 Implementation Plan

> Execute inline using superpowers:executing-plans and test-driven-development.

**Goal:** Expose Kinect v2 color, infrared and metric depth to Linux applications.
**Architecture:** libfreenect2 capture → tested pixel conversion → V4L2 write.
**Tech Stack:** C++17, CMake/CTest, Python standard-library test runner, systemd.
**Spec:** ../specs/2026-11-01-kinect-v4l2-design.md

## Global Constraints

Arch Linux first; three independently selectable outputs; 16-bit little endian
millimetres for depth; no PAM edits; no module unloading; headless CPU default.
The supplied .git is an empty, read-only directory, not a usable Git repository.
Work in the supplied workspace; no worktree or commits are possible here.

## Review Focus

Nonfinite sensor values → black/invalid pixels; unavailable GPU pipeline → clear
error before USB access; negotiated padding → correct row packing; short writes
→ fatal error without splitting frames; missing sensor → bounded failure/restart.

tests/test_cli.py, main.cpp, CMakeLists.txt.
Interfaces: Options parse_options(int,char**); bgrx_to_yuyv, ir_to_gray,
gray_to_yuyv, depth_to_y16, depth_to_gray with explicit element counts.
